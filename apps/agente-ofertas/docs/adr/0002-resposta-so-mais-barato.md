# Resposta lista a Oferta mais barata por tipo vendável

Para cada tipo vendável que vale no Item, a Resposta inclui só a(s) Oferta(s) com o menor preço efetivo (`valorPromocional` se houver promoção, senão `valor`); empate lista todas. Marca e tamanho vão na linha. Vários tipos que valem: um sub-bloco por Produto — não um mínimo entre tipos. Marca no Item restringe. Formato em lista (bloco por Item, `- Mercado — preço / tamanho`). Rejected: listar todos os Mercados (ruído no WhatsApp), listar todas as Marcas do tipo, e preço unitário normalizado por medida (fica para um ADR futuro).
