# Resposta lista só o Mercado mais barato

Para cada Item com um Produto, a Resposta inclui só a(s) Oferta(s) vigente(s) com o menor preço efetivo (`valorPromocional` se houver promoção, senão `valor`); empate lista todos. Formato em lista (bloco por Item, `- Mercado — preço`). Rejected: listar todos os Mercados (ruído no WhatsApp) e preço unitário normalizado por medida (fica para um ADR futuro).
