# Falha de Extração keeps motivo and rejected candidate

A Falha de Extração persists a stable motivo code, an optional free-text detalhe, and a copy of the rejected candidate payload — not only a message or an index into the Extrator response. Querying Redis must explain what failed without opening Artefatos; codes stay aggregatable in tests and ops, while detalhe carries the offending field or value. The raw Extrator Artefato remains the full transcript; each Falha is a self-contained validation outcome for that Documento.
