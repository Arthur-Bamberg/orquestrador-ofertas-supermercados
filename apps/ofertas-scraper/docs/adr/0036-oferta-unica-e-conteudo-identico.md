# Oferta única no catálogo; Documento com impressão digital e atalho de conteúdo idêntico

Oferta is a unique catalog observation: identity is Produto + Mercado + valor + quantidades + Medida + vigência + promoção + Comparativo + Marca (absent Marca is part of the key). Fonte, discovery day, and Documento do not distinguish. N Documentos may associate to the same Oferta; a re-encounter associates instead of cloning. On Documento reprocess, associations and Falhas for that Documento are replaced; an Oferta no longer referenced by any Documento is deleted.

Documento stores a SHA-256 fingerprint of the downloaded PDF. After download, if a prior `concluido` Documento exists for the same Fonte + filename with the same fingerprint, today’s Documento becomes `concluido` by identical content: it references that prior Documento, reuses the same Oferta associations (same IDs), skips raster/Extrator, creates no new Ofertas or Falhas, and keeps Artefatos limited to the downloaded PDF plus that pointer. `parcial` / `falhou` priors do not trigger the shortcut. Rejected: copying Oferta rows per day (duplicates the filtrable set), skipping the day’s Documento entirely (loses discovery trail), and matching across Mercados/Fontes by filename alone.
