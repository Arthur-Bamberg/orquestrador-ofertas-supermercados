# Extrator stub for local job and tests; Gemini/Cursor behind the same port

Application and tests depend only on the Extrator port. For local `RunDailyJob` development and automated tests without an Extrator API key (or with `EXTRATOR_STUB=1`), DI wires a stub/fake Extrator (fixture candidatos or controlled empty/error responses). Production wiring uses Gemini (`GEMINI_API_KEY`, `EXTRATOR_PROVIDER=gemini`) or Cursor (`CURSOR_API_KEY`, `EXTRATOR_PROVIDER=cursor`) — same prompt/schema contract; Cursor goes through the local Agent SDK bridge (ADR 0034). With `EXTRATOR_PROVIDER=auto` (default), DI wires Gemini-first then Cursor on rate-limit with daily quota skip (ADR 0037) — supersedes earlier auto preference for Cursor. Choosing the implementation is a composition concern in `cmd` / presentation — never a branch inside domain or use-case logic.
