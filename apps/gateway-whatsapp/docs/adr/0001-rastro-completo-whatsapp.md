# Rastro completo do canal no schema whatsapp

O gateway persiste toda Mensagem viva ingerida (direta; reacção; mídia) no schema `whatsapp`. Contato/Conversa guardam o JID de telefone. History sync, grupo e Status eram do recorte whatsmeow — o rastro antigo pode permanecer; a Cloud API não os ingere ([ADR 0020](../../../docs/adr/0020-gateway-whatsapp-cloud-api.md)). Allowlist como portão de Ack/`POST /envios` do produto: superseded by workspace [ADR 0019](../../../docs/adr/0019-aceite-no-contato-em-vez-de-allowlist.md) (Allowlist fica só no compositor do Operador). Rejected: silêncio no INSERT (feature-loop antigo D4) e presença/digitando/chamadas (não são Mensagem).
