# Apps run in root Compose; Dockerfile per hosted app

Local `docker compose up` runs PostgreSQL plus the long-running apps (`ofertas-api`, `ofertas-backoffice`, `gateway-whatsapp`, `agente-ofertas`). `ofertas-scraper` and `ofertas-web-scraper` stay one-shot CLIs in their own images (`docker compose run --rm`, profile `jobs`). Each hosted app has `apps/<name>/Dockerfile`. In-container `DATABASE_URL` uses hostname `postgres`; the root `.env` keeps `localhost` for host-side `go run` / `psql`. Pipeline ops from the API exec a compiled scraper binary (`SCRAPER_BIN`) inside the API image so the scraper CLI remains the execution boundary (ADR 0005). This is the “later app services” from ADR 0004.
