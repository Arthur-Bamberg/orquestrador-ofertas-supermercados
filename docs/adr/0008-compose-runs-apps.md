# Apps run in root Compose; Dockerfile per hosted app

Local `docker compose up` runs PostgreSQL plus the long-running apps (`ofertas-api`, `ofertas-backoffice`, `gateway-whatsapp`, `agente-ofertas`, `ofertas-scraper-v2`). `ofertas-scraper` stays a one-shot CLI in its own image (`docker compose run --rm`, profile `jobs`). Each hosted app has `apps/<name>/Dockerfile`. In-container `DATABASE_URL` uses hostname `postgres`; the root `.env` keeps `localhost` for host-side `go run` / `psql`. Pipeline ops from the API exec a compiled scraper binary (`SCRAPER_BIN`) inside the API image so the scraper CLI remains the execution boundary (ADR 0005). Testar Mercado (`POST /api/ops/testar`) uses in-container `COLETA_URL=http://ofertas-scraper-v2:8092` for Fonte `tipo=site` (ADR 0015). This is the “later app services” from ADR 0004.
