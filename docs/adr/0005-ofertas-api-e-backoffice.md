# Ofertas API and backoffice as separate apps

Local backoffice needs HTTP CRUD/filters over the shared catalog plus pipeline operations (daily run, Fonte discovery, Documento reprocess). We add `apps/ofertas-api` (long-running Go HTTP) and `apps/ofertas-backoffice` (Vite + React + TypeScript SPA), leaving `ofertas-scraper` as the one-shot CLI job. Rejected: embedding HTTP in the scraper binary (mixes cron CLI with a server) and a single process that serves API+UI (couples deployables). Shared domain access is extracted to `modules/ofertas-store` (ADR 0001 / 0006). Persistence is PostgreSQL (ADR 0006); this ADR originally assumed Redis. Auth of the Operador on the backoffice is ADR 0018 (this ADR’s “no auth in the MVP” no longer holds).
