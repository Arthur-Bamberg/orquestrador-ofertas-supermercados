# Ofertas API and backoffice as separate apps

Local backoffice needs HTTP CRUD/filters over the shared Redis catalog plus pipeline operations (daily run, Fonte discovery, Documento reprocess). We add `apps/ofertas-api` (long-running Go HTTP) and `apps/ofertas-backoffice` (Vite + React + TypeScript SPA), leaving `ofertas-scraper` as the one-shot CLI job. Rejected: embedding HTTP in the scraper binary (mixes cron CLI with a server) and a single process that serves API+UI (couples deployables). Shared Redis/domain access is extracted to `modules/` when the API becomes the second consumer (ADR 0001 / 0002). No auth in the MVP (local only).
