# Operador no backoffice; máquina com GATEWAY_TOKEN

The backoffice is no longer anonymous (supersedes “no auth / local only” in ADR 0005 and the open rastro + `VITE_GATEWAY_TOKEN` in ADR 0009 / 0017). An **Operador** identifies with nome + senha (bcrypt in Postgres schema `backoffice`; no CRUD UI). Catalog, Conversa rastro and Canal require that identification via httpOnly cookie. Service-to-service calls keep Bearer `GATEWAY_TOKEN` (Lista, Coleta, envio da Resposta, Testar Mercado as client); that secret is not the Operador’s password and is not baked into the SPA. Nginx (Compose) and Vite (host) proxy `/api` and `/gateway` on the SPA origin so the cookie reaches both apps. Rejected: entity Usuário, roles, login CRUD, and letting the machine token mutate Canal or catalog (Desparear left with pairing in ADR 0017, removed in ADR 0020).
